# random_matrices

Лабораторная 2: свойства случайных матриц.

## Установка

    pip install -e ".[dev]"

## Запуск эксперимента

    python run_experiment.py

Скрипт создаст папку `figures/` и сохранит туда:
- `gaussian.png` — гистограммы для гауссова ансамбля (2×2, 4×4, 16×16)
- `bernoulli.png` — то же для ансамбля ±1

Поверх каждой гистограммы — теоретическая кривая Вигнера (формула 15).

## Аналитика для 2×2 и ±1

    python analytic_2x2.py

Печатает возможные значения нормированной разности и их вероятности.

## Тесты

    pytest tests -v
